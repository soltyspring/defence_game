# 10라운드 단위 일러스트 배경

Built-in `image_gen`으로 생성한 오리지널 배경. 생성일: 2026-11-13.
외부 게임 이미지를 배포 자산으로 사용하지 않았다. PNG 원본은 수정 없이 보존한다.

참고: [Kingdom Rush](https://www.ironhidegames.com/Games/kingdom-rush)의 지역별 풍경 구분,
[Kingdom Two Crowns](https://kingdomthegame.com/kingdom-two-crowns/)의 횡스크롤 풍경과 깊이감.
실제 게임은 자체 구도와 빵집 세계관으로 새로 제작했다.

풍경과 지면은 같은 원본의 서로 다른 영역을 사용한다. 풍경만 느리게 움직이고 지면은
월드에 고정된다. 좌우 반전 반복으로 끝부분을 연결하며 병사 발 위치를 챕터별로 맞춘다.
한 번에 현재 챕터 텍스처만 로드하고 선형 필터로 축소해 회화 질감을 유지한다.

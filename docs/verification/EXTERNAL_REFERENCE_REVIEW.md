## How to use this reference here (short guide)
1. Use its skill texts as checklists only. Do not copy hooks or agents; do not run its shell scripts.
2. Before calling any test "evidence", ask: does it assert something that can fail, at which commit, under which condition (HEAD vs workspace)?
3. For visual claims, keep the image, its commit and its device/viewport; otherwise the verdict is NOT ASSESSED.
4. For slice/release gates, any NO or NOT ASSESSED blocks "validated"; report it, do not average it away.

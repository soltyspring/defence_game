# 제빵 대장과 밀가루 견습생

이 폴더에는 ChatGPT로 그린 오른쪽 방향의 3×2 원본 시트를 보관한다.
제빵 대장은 사용자가 올린 걷기 시트를 기준으로 나머지 동작을 맞췄다.
견습생은 대기·빈손 이동·포대 집기·포대 운반을 사용한다. 집기 시트는 1–3컷에서
빈손으로 몸을 낮추고 4–6컷에서 포대를 들어 올린다. 운반 프레임에도 포대가 그려져 있다.

`python tools/art/gpt_import.py characters`로 전투용 투명 아틀라스를 다시 만든다.
제빵 대장의 타격 프레임은 기존과 같은 4번째 칸이다.
제빵 대장의 모든 동작은 공통 팔레트로 변환한다. 전투 크기에서 사라지기 쉬운 눈동자와
흰자는 프레임별 위치에 같은 도트색으로 찍는다. 쓰러짐의 마지막 두 컷은 원본처럼 눈을 감는다.

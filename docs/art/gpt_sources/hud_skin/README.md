# 전투 상단 HUD 스킨

이 폴더의 시트는 사용자가 ChatGPT에서 생성해 제공한 원본이다. 별도 제3자 에셋 팩을 사용하지 않았다. `python tools/art/import_battle_hud_skin.py`로 자홍 여백을 제거하고 8배 격자에서 PNG 세 장을 추출한다.

| 에셋 | 규격 | 표시 |
| --- | --- | --- |
| base_health.png | 128×20 | 양쪽 기지 체력의 공용 틀. 아이콘·체력 채움·피해 표시와 깜박임은 코드에서 그린다. |
| minimap.png | 96×40 | 기존 미니맵 틀. 경로·유닛·카메라와 터치 영역은 코드에서 관리한다. |
| speed.png | 40×40 | 배속 버튼 바탕. x1/x2 문구와 상태별 밝기는 코드에서 관리한다. |

밀가루·기력 영역과 일시정지 버튼은 이번 스킨의 대상이 아니다.

가독성 보정: 기지와 미니맵은 공통 세이지색/말린 장미색을 쓴다. 적 게이지에는 줄무늬를 유지하며, 피격 잔상은 어둡게 표시한다. `speed_active.png`는 원본 버튼(40×40)을 같은 변환 스크립트로 호박색으로 바꾼 x2 상태다. 두 상태 모두 자홍색이 없고 15색 이하다.

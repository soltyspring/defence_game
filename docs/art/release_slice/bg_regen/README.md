# R41–R100 배경 재생성본 (ChatGPT A/B → 반복 타일)

`source/<name>_A.webp`, `_B.webp`는 [PROMPTS.md](PROMPTS.md)로 ChatGPT에서 생성한 원본 12장이다.
`tiles/<name>.png`는 `python tools/art/release_slice/bg_tiles.py`로 만든 4096×704 결과다.

## 만드는 방법

1. A와 B를 각각 544×176 논리 픽셀로 줄인다.
2. 두 이음매(A|B, 반복 시 B|A)를 32px씩 겹친다. 겹친 구간에서 두 그림의 색 차이가 가장 작은 위→아래 경로를 따라 자른다. 섞지 않으므로 반투명하게 겹친 흔적이 생기지 않는다.
3. 디더링 없이 32색으로 줄이고, 최근접 보간으로 4배 키운다.

결과는 1024×176 논리 픽셀, 좌우 반전 없이 반복된다.

## 게임 통합 (2026-11-13 적용)

- 6장을 `assets/backgrounds/chapter_tile_layers/`에 복사했다.
- `src/gameplay/painted_chapter_backdrop.gd`의 `TRIM_GROUND_ROWS`를 챕터별 배열로 바꿨다. R01–R40은 20, R41–R100은 0이다.
- R71–80 길 색을 따뜻한 갈색으로 바꿨다.
- 검증: `tests/acceptance/test_painted_chapters.gd`(R01–R100 641개 검사)를 통과했다.
- 실제 게임 화면은 `tests/art_preview/capture_late_chapters.gd`로 확인했다. main에는 R41 이후 라운드가 아직 없어서, R40을 시작한 뒤 배경만 41–91번으로 다시 만들어 찍었다.

## 남은 약점

- **눈 배경이 많다.** 채석장, 요새, 오로라가 모두 눈 배경이다. R21–30 서리까지 합치면 10챕터 중 4챕터가 눈이다.
- **뿌리 전당이 복잡하다.** 질감이 촘촘해서 다른 챕터보다 화면이 시끄럽다. 유닛은 외곽선 덕분에 읽힌다. 바닥 색이 A와 B에서 조금 달라 이음매에 작은 단차가 있다.
- **균사 핵실은 원근 구도다.** 중앙 계단이 깊이 방향으로 들어가는 그림이라, 옆으로 흐르는 다른 배경보다 원근감이 강하다.
- **원본이 진짜 도트는 아니다.** ChatGPT 원본은 도트처럼 보이는 일러스트라서, 32색 정리 후에도 넓은 면에 잔 점이 남는다.

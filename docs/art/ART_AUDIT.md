# ART_AUDIT.md — hostile visual/type review (owner: 03-art)
Round 1 · 2026-10-31. Method adapted from the gongmojeon skill (QUALITY_REVIEW.md): observed problem → source/screen → player impact → severity → owner → fix → acceptance check → recheck evidence. No invented scores, user research or device results. Severity: P1 = release risk, P2 = clear quality defect, P3 = polish. "Fixed" here means fixed in 03's files and re-checked with the same attack. Runtime wiring by other owners is listed separately.

## Strongest reasons to reject the current visuals (before this round)
1. Korean text had no bundled font, so Android could show tofu (04 measured 127/131 UI characters missing from the fallback font).
2. Text sizes and non-integer device scales break the pixel grid (measured, see A2/A3).
3. In crowded melee the two armies merge into one mass. Faction is carried only by hue (docs/art/evidence/battle_cap_zoom4_fractional.png).
4. The theme is unapproved (Q1 PENDING), so all character art may need redrawing. 03 cannot fix this alone.

## Round 4 (2026-10-31 09:45) — in-game readability, r01/r05/r10, dense melee
Method: `pwsh tools/art/run_godot_readability.ps1 -Tag <before|after>`. Isolated temp project with its own fresh import (independent of the main-tree cache). 02's draw order. 9 scenes (r01/r05/r10 × meadow / dark = black 65 % over the background / bright = white 45 % over the background), each with 11–13 allies and 11–14 enemies in melee, plus projectiles in flight and impact fx at the front. Rendered by Godot 4.7.2 at 640×360 1× and 1280×720 2×, window on the secondary monitor (screen 1). The Godot 1× captures equal the Python composite used for the metrics (max channel diff ≤ 1, 0 px > 2) in all 9 scenes. Thresholds were fixed before measuring and are internal, unvalidated by players: silhouette ≥ 60 % of the perimeter at ΔL* ≥ 15; crowd-visible ≥ 40 %; impact fx covers ≤ 35 % of its target; projectile pixels separated from the background by ΔL* ≥ 20 ≥ 60 %. The first projectile metric (mean ΔL*) was replaced after run 1 because it averages a dark outline with a light core to a mid tone; both values stay in metrics_*.json.
"before" = committed HEAD art (metrics_before.json). "after" = this revision (metrics_after.json).

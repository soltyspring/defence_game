# 10라운드별 회화 배경

1–40라운드의 배경을 네 장의 오리지널 회화 PNG로 교체한다. 코드 도형으로 만든
풍경은 이미지 누락 시 대체 경로로만 남는다. 전투 병사, 기지, UI와 판정은 유지한다.

| 구간 | 장소 | 색과 재질 |
|---|---|---|
| R01–R10 | 밀밭 마을 | 황금빛 밀, 테라코타 지붕, 석재 풍차 |
| R11–R20 | 가을 과수원 | 호박색 단풍, 나무 착즙장, 오래된 물레방아 |
| R21–R30 | 얼어붙은 제분소 | 청색 눈과 얼음, 따뜻한 창문 불빛 |
| R31–R40 | 균사 동굴 | 청록빛 균사, 보랏빛 버섯, 동굴의 깊이 |

원본: `assets/backgrounds/painted_chapters/{meadow,orchard,frost,nest}.png`.
각 이미지 2172×724, 원본 합계 약 11.6 MiB. 한 전투에서는 해당 챕터 원본 한 장만
사용하며 픽셀당 4바이트 기준 약 6 MiB다. 기존 기지/제분소 아틀라스는 별도로 유지한다.
제작 방식, 참고 링크, 최종 프롬프트는 같은 디렉터리의 `GENERATION.md`에 기록한다.

## 적용

- `painted_chapter_backdrop.gd`가 10라운드 구간별 PNG를 선택한다.
- 정식 게임의 `lane_backdrop.gd`가 이 배경을 사용한다. 프리뷰는 별도 작업으로 추가된
  `art_preview/painted_backdrop.gd`의 재조명 버전을 사용하며 `--bg=pixel` 선택도 유지한다.
- 풍경은 카메라 이동량의 28%로 이동한다. 이미지 하단의 길은 월드에 고정한다.
- 길의 높이는 원본마다 따로 맞춰 발이 지면 위에 놓이게 했다.
- 좌우 끝은 반사 반복으로 연결한다. 높이가 확장되는 화면에서도 가장자리 근처는
  원본을 반사해 구름과 흙의 질감을 유지한다.
- 기존 보스 등장/노출 효과와 카메라의 픽셀 정렬 계약을 유지한다.

## 검증

`tests/acceptance/test_painted_chapters.gd`: 40개 라운드의 자산 선택, 챕터 경계,
실제 렌더러 장착, 풍경과 길 사이 연결, 발 높이, 줌/카메라 이동 시 지면 고정,
보스 노출 표시를 검사한다. 기존 backdrop 및 pixel camera 회귀 검사도 실행한다.

실제 전투 캡처는 `tests/acceptance/capture_backdrop.gd`로 R01/10/11/20/21/30/31/40의
시작·중앙 교전·적 기지 구간을 확인한다. 640×360, 1280×720와 1600×720을 사용한다.
렌더링은 WSL/Xvfb의 별도 가상 화면, Windows 검사는 전용 APPDATA에서 실행한다.
긴 실행은 `coordination/heavy_run_detached.ps1`로 직렬화한다.

### 현재 상태와 일괄 테스트 대기

2026-11-13 사용자 요청으로 추가 테스트를 나중에 모아 진행한다.

- 요청 전 완료: 챕터 검사 249건, 기존 배경 검사 615건, 카메라 검사 8,992건 통과.
- 세 가지 해상도의 전투 캡처 52장 생성. 큰 화면 위/아래의 늘어진 질감을 수정한 뒤
  같은 구도를 다시 확인했다. 최신 소스와 결합한 네 챕터 교전 캡처도 생성했다.
- 캡처 종료 시 오디오 리소스 정리 오류가 남는다. 변경 전 배경으로 실행한 대조 캡처에도
  동일한 music_menu/music_battle Ogg 리소스 경고가 발생했다. 캡처 작업 전체를 성공으로
  표기하지 않으며, 일괄 테스트에서 오디오 종료 정리와 함께 재확인한다.
- 대기: 최종 통합 회귀 검사, Windows 패키지 내 네 PNG 로딩과 챕터별 실행 확인.

일괄 테스트 때 `tools/build/build_windows.ps1`로 커밋된 소스에서 Windows 패키지를 만들고
메뉴와 각 챕터를 확인한 뒤 루트 `BakeryKnights.exe`를 갱신한다. 이번 변경에서는 기존의
검증된 실행 파일을 유지했다. 검증 로그와 실행 파일은 Git에 넣지 않는다.

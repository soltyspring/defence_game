## 무엇을 재나

- 같은 카드의 두 상태를 같은 위치에서 비교한다.
  - 시안 A·B·C: r06 t46 장면(기준선에서 5장 모두 살 수 있음)을 "as_captured"(살 수 있음)와 "all_dimmed"(살 수 없음)로 그린 두 장.
  - 지금 04 화면(기준선): 같은 카드가 r06에서 살 수 있고 r08에서 살 수 없는 통식빵·화덕포 2장(실제 캡처).

  (`touch_button.gd` 157·197행). 몸통은 04의 `C_DISABLED` 또는 06의 `card_frame_disabled`.

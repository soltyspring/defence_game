# UI 그래픽 합격 기준 (06-art-ui)

원인과 측정 방법: `UI_ART_AUDIT.md`. 판정 도구: `tools/art/ui_art/ui_audit.py --criteria`(빌드된 아틀라스),
`tools/art/ui_art/card_preview.py --criteria`(빌드 전 미리보기, 03의 char_player idle 프레임 사용).
기준 상수는 `ui_audit.py`의 `CRIT`에 있다. 색은 모두 팔레트(`pixel.py`, 03 소유) 안에서 고른다.

## 기준을 정한 순서 (정직하게 적음)

처음 기준은 다시 그리기 전에 `ui_audit.py`에 넣었다: C1 20, C2 12(단, 모양이 다르면 면제), C3 0.80,
인물 대비 3.0(인물 전체 픽셀 밝기 중앙값), 판 대 몸통 3.0(몸통을 04 `C_PANEL` #3d2519로 가정), 스킬 3.0.
첫 미리보기 뒤에 아래처럼 바꿨다. 모두 더 엄격하거나 실제 화면에 더 가까운 쪽이며, 느슨하게 바꾼 것은 없다.

1. 몸통 색을 가정값 #3d2519에서 캡처 실측 #694226으로 바꿨다. 기존 판의 값이 1.72에서 1.06으로 나빠졌다.
2. 인물 대비를 "인물 전체 밝기 중앙값"에서 "판에 닿는 인물 가장자리"로 바꾸고 3.0을 4.5로 올렸다.
   전체 중앙값은 인물 내부 색(빵 색)과 외곽선이 섞여서, 판과 인물이 갈리는지를 재지 못한다. 기존 판은 두 방식 모두 탈락이다(2.18, 1.88).
   새 배지의 옛 방식 값은 1.63–3.57로 낮다. 밝은 판 위에 중간 밝기 빵 인물이 K 외곽선으로 갈리는 구조라서다. 참고로 표에 남긴다.
3. C2를 "모양이 다르면 면제"에서 "색과 모양 모두"로 바꿨다(사용자 요구: 모양과 색 모두로 구별).
4. 스킬 기준을 3.0에서 4.5로 올렸다. C7 로고 기준을 새로 넣었다.
5. `plate_info()`가 판 색을 찾을 때 K(외곽선)를 빼고, 테두리를 고정 2 px 띠 대신 실루엣 바깥 2겹으로 잡게 고쳤다.
   모양 있는 배지에서 외곽선이나 베벨이 판 또는 인물로 잘못 잡히던 문제다. 기존 정사각형 판에서는 결과가 같다.

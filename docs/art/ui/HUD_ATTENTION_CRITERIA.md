## 기준
| ID | 질문 | 기준 |
|---|---|---|
| Z1 | 카드 줄이 바닥에서 튀어나와 보이는 정도가 유닛보다 크지 않은가 | 카드 줄 평균 L*와 바로 위 흙 띠(카드 위 3–8 px, HUD 아닌 픽셀) 평균 L*의 차 \|ΔL*\| ≤ 같은 장면 유닛의 \|ΔL*\| 중앙값(07 `unit_dL_median`) |
| Z2 | 카드 줄이 유닛보다 밝지 않은가 | 카드 줄 평균 L* ≤ 유닛 픽셀 평균 L* |
| Z3 | 카드 줄의 대비 밀도가 지금보다 크게 늘지 않는가 | 카드 줄 안 평균 \|∇L*\| ≤ 04 지금 화면 값 × 1.10 (같은 장면·같은 새 배경) |

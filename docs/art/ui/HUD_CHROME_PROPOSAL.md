늘림 규칙(모든 9-slice): 가장자리 띠는 늘어나는 방향으로 같은 색이고 가운데는 한 색이다. 모서리 깎임·리벳은 여백 안에 있다.
그래서 `NinePatchRect`의 STRETCH와 TILE 어느 쪽이든 픽셀이 깨지지 않는다(`chrome_preview.py`: STRETCH PASS 13/13).
Godot 연결 예: `NinePatchRect.texture = UiStyle.ui_icon("card_frame")`, `patch_margin_left/top/right/bottom = 6`,
`axis_stretch_horizontal/vertical = STRETCH`, 필터 nearest(프로젝트 기본값). 2배 화면은 논리 크기 그대로(정수배 확대).

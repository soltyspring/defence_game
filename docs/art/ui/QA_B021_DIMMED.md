07 09:1x: 02의 780c30a 이후 07 고정 세트의 r08·r10에서 유닛 카드 5장이 모두 어두운 상태이고, 롤빵병/화덕포·통식빵/프레첼 두 쌍이
U1을 실패한다(`docs/verification/art_compare/e8c6d96.md`). 기준은 그대로: 화면의 모든 쌍이 (보통 ΔE ≥ 10이고 deutan ΔE ≥ 8) 또는
16×16 모양 거리 ≥ 12.

## 1. 어두운 상태는 어디서 만들어지나
- **04 코드다.** `src/ui/touch_button.gd`가 살 수 없는 버튼의 아이콘을 `Color(1, 1, 1, 0.45)`로 곱해 그린다(HEAD 88d431a, 173행
  근처). 몸통은 코드로 그리는 `C_DISABLED` 상자다. 06의 `card_frame_disabled` 그림은 아직 어떤 화면에도 쓰이지 않는다.
- 공유 작업 폴더의 `touch_button.gd`에는 04의 커밋 안 된 값 0.70이 있다(04 07:3x 회신의 FEAT_SHA). HEAD와 07 캡처는 0.45다.

## 2. 07 값 재현과 후보 비교 — 07 실제 캡처(e8c6d96 ko_1x)에서 24×24 아이콘만 바꾼 합성, 실제 화면 증거 아님

- U1을 통과하는 것은 K1(α .70, 자르기 상관없이)과 K2+T1이다. K1이 가장 작은 변경이다: 04의 값 하나, 새 프레임 없음, 아틀라스 재빌드 없음.

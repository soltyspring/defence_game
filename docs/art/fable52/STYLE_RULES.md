# Fable 5.2 스타일 규칙 (2026-11-11)

대표 구간(1–10 밀밭 마을)과 대표 캐릭터 4종에 적용한 규칙. 나머지 구간·캐릭터는 이 규칙으로 만든다.
생성기: `tools/art/world/lane_set.py`(배경 세트), `tools/art/chars_fable.py`(캐릭터), 적용: `src/gameplay/lane_backdrop.gd`.

## 배경 레이어

| 레이어 | 시차 | 내용 | 규칙 |
|---|---|---|---|
| 0 하늘 | 0.0 | 4단 색면 | 변경 없음 |
| 1 구름 | 0.08 | 3박스 구름 | 변경 없음 |
| 2 능선 | 0.22 | 2색 다각형 | 낮은 대비 덩어리 |
| 3 밭 | 0.4 | 넓은 밀 띠 1개 + 420px 간격 볏단 | 고랑·기둥 반복 금지. 오염은 길이 23%·32% 지점부터 비스듬한 2단 색면으로 식힌다 |
| 4 세트 | **1.0 (월드 고정)** | `lane_set_v2.png`의 home / blight | 두 기지를 감싸는 한 장씩. 가운데 구간은 비운다 |
| 5 길 | 1.0 | 풀 가장자리·길·흙 | 아군 기지 앞 밝은 앞마당, 둥지 앞 어두운 포자 자락 3단 |

- **유닛 띠(지면 위 44px) 뒤에는 평평한 덩어리만.** 담·생울타리·안개까지. 창문·차양·간판·포자구는 그 위에서 시작한다.
- **배경에는 휘도 0.38보다 어두운 색과 어두운 외곽선을 쓰지 않는다.** 어두운 외곽선은 유닛·기지 전용.
- 최소 형태 3px, 디더·1px 잔점 금지. 같은 소품을 일정 간격으로 나열하지 않는다(간격·높이를 다르게).
- 길 찾기 표식: 아군 쪽 풍차(제분소) + 빵집 굴뚝 연기, 가운데 이정표 2개(30%·55%), 적 쪽 높이가 다른 곰팡이 줄기 6개 + 둥지.
- **팔레트**: 아군 구역 따뜻한 크림·테라코타(`#e6d9b9` 벽, `#bd7d5e` 지붕, `#93a874` 생울타리) → 오염지 차가운 회녹·청록(`#a6b6aa` 안개, `#5f7f7c` 갓, `#6fa3a6` 포인트). 흑백에서도 아군 쪽이 밝고 적 쪽이 어둡다.
- **구간 확장**: 세트 시트의 home/blight 두 영역만 구간별로 다시 그리고(같은 크기·같은 기준선 `ground-12`), 레이어 0–3·5는 기존 `modulate`(과수원 `e3d0a8/d9c3a2`, 서리 `a8bddc/a9bfd1`)로 재사용한다. 구간마다 고유 표식은 하나만 추가한다.
- `lane_set_v2.png`가 임포트되지 않았으면 코드가 자동으로 기존 v1 파노라마를 쓴다.

## 캐릭터

- **계약 유지**: 프레임 크기·피벗·애니 이름·프레임 수·fps·`hit_frame`은 기존과 같다(`contract_diff.py` 변경 0). 피벗 = 발 중앙 아래: 영웅 48×48 (22,47), 일반 32×32 (13,31), 보스 64×64 (28,63).
- **외곽선**: 바깥 1px 최암색(`K`) 통일. 겹치는 덩어리 사이에만 안쪽 윤곽 1px. 선택적 외곽선(밝은 쪽 생략)은 쓰지 않는다 — 배경이 밝아 실루엣이 끊긴다.
- **빛**: 왼쪽 위. 덩어리마다 기본·그늘(오른쪽 아래)·하이라이트(왼쪽 위) 3단까지.
- **진영 = 형태 + 색**: 아군은 네모·둥근 빵 몸통, 밝은 속살(크림) + 구운 테두리(갈색) + 붉은 포인트 1개. 적은 처진 비대칭 갓·가는 줄기·갈고리, 회녹 몸 + 청록 눈. 적에게 크림·황토 계열, 아군에게 청록을 쓰지 않는다.
- **역할 = 실루엣**: 몸통 비율과 무기를 먼저 정한다. 근접=몸 옆에 세운 칼, 원거리=던지는 팔을 뒤로 뺀 자세, 탱커=넓고 낮은 몸+방패, 속공=앞으로 쏠린 몸, 공성=몸보다 큰 장비. 색만 바꾼 변종 금지.
- **공격 예고(3박자)**: 준비(무기를 머리 위·뒤로, 몸이 뒤로 젖음) → 접촉(`hit_frame`, 호 모양 궤적) → 회복(무기가 아래·앞에 남음). 준비 프레임은 대기 실루엣과 4px 이상 달라야 한다. 보스는 준비 프레임에 무기 끝이 청록으로 빛난다. 예고색은 진영색을 따른다(아군 노랑, 적 청록).
- **얼굴**: 눈 1–2px, 아군은 검은 점눈 + 볼터치, 적은 청록 가로 눈. 영웅·보스만 머리 장식(요리모, 줄기 왕관)을 갖는다.
- **실제 크기 확인**: 1x 전투 프레임, 흑백, 같은 유닛 밀집, 양 진영 겹침에서 본다(`tools/art/world/lane_mock.py`).

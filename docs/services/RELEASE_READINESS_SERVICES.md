# Release readiness for ads, billing and privacy (owner: 06-services)
Version: 1. Sources checked: **2026-10-31** (KST) by fetching the official pages listed below. Requirements are paraphrased, not quoted; re-check each URL before release because policies change. Content was rephrased for compliance with licensing restrictions.

Status: **nothing here is integrated.** No ad SDK, billing library, consent SDK, server, account or key exists in the project. The business model is not decided (DECISIONS.md D9 DEFAULT); see OPEN_DECISIONS.md for what the user must decide, one question at a time through 01. This file does not decide anything and does not install anything.

Applies-when column: `always` = any Play release, `IAP` = only if in-app purchases are approved, `ads` = only if ads are approved, `kids` = only if children (or unknown-age users) can see ads, `accounts` = only if the game adds user accounts.

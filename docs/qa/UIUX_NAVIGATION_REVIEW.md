# 화면 이동·탭 UI/UX 점검 (2026-11-15)

기준 커밋 `99493a1`. 게임 UI/UX 점검 기준(앵커·배율 정책, 안전 영역, 화면 스택과 뒤로 가기, 상태 표시, 색만으로 전달하지 않기)으로 모든 화면과 탭을 실제로 띄워 캡처하고, 화면 전환 코드를 따라가며 정리했다.

- 캡처: `docs/qa/uiux_review_20261115/` (640×360 기준 12장, 19.5:9 폰 비율과 4:3 태블릿 비율 묶음 각 2장)
- 캡처 방법: 저장 파일을 분리한 상태로 각 화면을 차례로 띄우는 임시 스크립트(R14까지 열림, 골드 2,400)를 640×360, 1560×720, 960×720에서 실행했다. 플레이어 저장은 건드리지 않았다.
- 배율 정책: 기준 해상도 640×360, `canvas_items` + `expand` + 정수 배율(`project.godot`). 화면 비율이 달라지면 남는 쪽으로 논리 화면이 넓어진다.

## 1. 화면 지도

```mermaid
flowchart LR
  T[타이틀] -- 시작하기 --> L[기사단 본부 로비]
  T -- 이어하기 --> R{출전 준비 필요?}
  T -- 설정 --> S[(설정 창)]
  L -- 뒤로 --> T
  L -- 라운드 선택 --> RS[라운드 선택]
  L -- 강화 --> U[(강화 창)]
  L -- 골드 상점 --> G[골드 상점]
  RS -- 뒤로 --> L
  RS -- 강화 --> U
  RS -- 라운드 타일 --> R
  R -- 예: 스킬 4개(R8)·유닛 6종(R30)부터 --> P[출전 준비: 유닛/스킬 탭]
  R -- 아니오 --> B[전투]
  P -- 저장 --> B
  P -- 뒤로 --> RS
  B -- 일시정지 --> PA[(일시정지)]
  PA -- 계속하기 --> B
  PA -- 다시하기 --> B
  PA -- 설정 --> S
  PA -- 메뉴 --> L
  B -- 종료 --> RE[결과]
  RE -- 메뉴 --> L
  RE -- 강화 --> U
  RE -- 다시하기 --> B
  RE -- 다음 라운드 --> R
  U -- 골드 구매 --> G
  U -- 닫기 --> 열었던 화면
  G -- 뒤로 --> L
  G -. 강화 창에서 왔을 때 .-> U
```

괄호 모양 `( )`은 화면 위에 뜨는 창이고 나머지는 화면 전환이다. 안드로이드 뒤로 가기는 창이 열려 있으면 창을 닫고, 없으면 화면별 뒤로와 같은 곳으로 간다(타이틀은 종료 확인).

### 이동 경로에서 걸리는 점

| # | 문제 | 근거 | 영향 |
| --- | --- | --- | --- |
| N1 | **편성(캐릭터) 화면에 직접 갈 길이 없다.** 출전 준비는 고를 것이 생겼을 때(스킬이 칸 3개보다 많아지는 R8부터, 유닛이 5종보다 많아지는 R30부터)만 라운드를 시작하는 순간에 뜬다. 로비·라운드 선택·결과 어디에도 '편성' 입구가 없다. | `roster.gd` `needs_choice`, `main_menu.gd` 로비 버튼 | R1–R7에는 캐릭터·스킬 화면을 아예 볼 수 없고, 그 뒤에도 라운드를 시작해야만 열린다. 전투 없이 구성을 둘러보거나 바꿀 수 없다. |
| N2 | **출전 준비의 '뒤로'는 늘 라운드 선택으로 간다.** 타이틀 '이어하기'나 결과 '다음 라운드'에서 왔어도 마찬가지다. | `roster.gd` `_back` | 온 곳으로 돌아가지 않아 흐름이 끊긴다. |
| N3 | **골드 상점의 '뒤로'는 늘 로비로 간다.** 결과 화면이나 라운드 선택의 강화 창에서 '골드 구매'로 들어가도 로비의 강화 창으로 돌아온다. | `gold_shop.gd` `_back`, `GoldShopCatalog.return_to_upgrades` | 결과 화면의 별·보상 정보로 다시 돌아갈 수 없다. |

| N5 | **상점 입구가 로비 오른쪽 위 작은 글자 버튼 하나뿐이다.** 라운드 선택·결과에는 없고, 강화 창을 거쳐야 한다. | 캡처 03, 06, 11 | 골드가 모자란 순간(라운드 선택, 결과)에 바로 갈 수 없다. |
| N6 | **설정은 타이틀과 일시정지에서만 열린다.** 로비에는 없다. | `main_menu.gd` `show_page` | 로비에서 소리를 줄이려면 타이틀로 돌아가야 한다. |
| N7 | **화면 전환이 화면 스택이 아니라 이름 지정 이동이다.** 각 화면이 돌아갈 곳을 직접 정한다(`cmd_open_screen(&"menu")` 등). | `app.gd` `show_screen` | N2·N3 같은 '온 곳으로 돌아가기'가 화면마다 따로 구현돼야 한다. |
| N8 | UI 테스트 7건이 옛 이동 규칙(결과·일시정지의 메뉴 = 라운드 선택)을 기대하고 있어 계속 실패한다. 현재 규칙은 '메뉴 = 로비'다(`ae2fd75`). | `tests/ui/test_ui.gd` | 진짜 회귀가 섞여도 묻힌다. 테스트를 현재 규칙에 맞춰야 한다. |

## 2. 화면별 분석

### 2.1 타이틀 (`01_title.png`)
- 좋음: 로고·주 버튼(시작하기)·보조 버튼 두 개의 위계가 분명하다. 버전 표시는 오른쪽 아래.
- 문제: 왼쪽 위 골드(2400)는 이 화면에서 할 수 있는 일과 관계가 없다. '이어하기'가 무엇을 이어하는지(다음 라운드 번호) 알 수 없다.
- 제안: 골드는 로비부터 보여 준다. '이어하기' 아래에 'R14 계속' 같은 한 줄을 붙인다(로비 카드처럼).

### 2.2 설정 창 (`02_settings.png`)
- 좋음: 한 화면에 모두 들어오고, 슬라이더 값이 숫자로도 나온다.
- 문제: 켜기/끄기·30/60에서 **선택된 쪽이 색으로만 구분된다**(주황 = 선택). 색약 사용자나 밝은 화면에서는 어느 쪽이 켜져 있는지 헷갈린다. '닫기'는 아래 가운데, 다른 화면의 '뒤로'는 왼쪽 위라 위치가 다르다.
- 제안: 선택된 버튼에 체크 표시나 테두리·눌린 모양을 더한다. 한 쌍 대신 스위치 하나로 바꿔도 된다.

### 2.3 기사단 본부 로비 (`03_lobby.png`)
- 좋음: 큰 그림 카드 두 장(라운드 선택, 강화)과 그 아래 한 줄 요약(다음 R1·별 0/300, 지금 강화 가능 10개). 강화 카드의 숫자 배지.
- 문제: 카드가 두 장뿐이라 가운데 아래가 비어 있다. **편성·상점·설정이 카드로 없다**(N1·N5·N6). '골드 상점' 버튼은 지갑 옆 작은 글자라 눈에 덜 띈다.
- 제안: 카드 3~4장(라운드 선택 / 강화 / **편성** / 상점)으로 늘리거나, 아래쪽에 작은 아이콘 줄(편성·상점·설정)을 둔다. 지갑(골드 칩)을 누르면 상점으로 가게 하면 모든 화면에 같은 입구가 생긴다.

### 2.4 강화 창 (`04_upgrades.png`)
- 좋음: 왼쪽 목록 / 오른쪽 상세(설명, 시연, 다음 레벨 수치 변화) 구조, 시연 애니메이션, 골드 구매 버튼이 항상 있다.
- 문제:
  - 영웅·유닛·합류 대기·빵집 강화가 한 목록에 섞여 5개씩 3쪽으로 넘긴다. 무엇이 몇 쪽에 있는지 모른다. 4:3에서는 12개가 한 번에 보여 오히려 낫다.
  - 행 오른쪽의 '▲'가 '살 수 있음'인지 '강화 가능'인지 설명이 없다.
  - '골드 구매'가 올리브색이라 비활성처럼 보인다(살 수 있을 때 밝아짐).
  - 닫기 버튼이 아래에 있어 다른 화면의 왼쪽 위 '뒤로'와 다르다.
- 제안: 위쪽에 탭 3개(영웅 / 병사 / 빵집)를 둔다. '▲' 대신 '가능' 배지나 비용 표시를 쓴다. 닫기를 왼쪽 위 '뒤로' 자리로 옮기거나 오른쪽 위에 ×를 둔다.

### 2.5 골드 상점 (`05_gold_shop.png`)
- 좋음: 보유 골드와 '테스트 구매는 청구되지 않음' 안내, 4개 팩의 골드·가격이 한눈에 보인다.
- 문제:
  - 오른쪽 위 '성장 팩'은 탭인데 일반 버튼처럼 생겼다. 지금 어느 분류를 보고 있는지(일반 골드 / 성장 팩) 표시가 없다.
  - 팩 아래 화면 절반이 비어 있고, 같은 안내 문구가 아래에 한 번 더 나온다.
  - 팩마다 '얼마나 이득인지'(보너스 %)나 강조(추천) 표시가 없다.
  - 뒤로가 늘 로비로 간다(N3).
- 제안: 위쪽에 '골드 / 성장 팩' 탭 두 개를 선택 상태와 함께 둔다. 팩 카드를 키워 골드 아이콘·보너스 배지를 넣는다. 아래 중복 안내는 지운다. 들어온 화면으로 돌아가게 한다.

### 2.6 라운드 선택 (`06_round_select.png`)
- 좋음: 10개 타일(2×5), 별 3개, 잠긴 라운드는 자물쇠, 보스 라운드는 이름 표시. 오른쪽 위 지갑과 '강화'.
- 문제:
  - 지금 몇 번째 묶음인지(11–20, 챕터 이름, 몇 쪽 중 몇 쪽) 표시가 없다. 좌우 화살표만 있다.
  - 다음에 할 라운드(R14)가 다른 타일과 똑같아 보인다.
  - 별이 작은 테두리 별이라 얻은 별과 못 얻은 별의 차이가 약하다.
  - 4:3에서 타일이 세로로 길게 늘어나 빈 갈색 기둥처럼 보인다(`ratio_4x3_a.png`).
- 제안: 위쪽 제목 옆에 '2장 · 과수원 (11–20)'과 쪽 점을 둔다. 다음 라운드 타일에 테두리 빛이나 '다음' 리본을 단다. 얻은 별은 채운 금색, 못 얻은 별은 어두운 빈 별로 대비를 키운다. 타일 높이에 상한을 두고 남는 공간은 가운데 정렬한다.

### 2.7 출전 준비: 유닛 탭 / 스킬 탭 (`07_roster_units.png`, `08_roster_skills.png`)
- 좋음: 위 = 출전 칸, 아래 = 보유 목록, '눌러서 넣기/빼기' 안내, 잠긴 유닛은 해금 라운드 표시, 아래 줄에 선택한 항목 설명.
- 문제:
  - 오른쪽 위 버튼이 '저장'인데, 라운드에서 왔을 때는 저장하고 **바로 전투를 시작한다**. 무슨 일이 일어날지 이름이 말해 주지 않는다.
  - 제목 '출전 5 / 5'가 스킬 탭에서도 유닛 수를 보여 준다(스킬 칸은 3/3).
  - 탭(유닛/스킬)이 왼쪽 위 작은 버튼이라 탭으로 읽히지 않는다. 선택된 탭은 색으로만 구분된다.
  - 출전 칸과 보유 목록에 같은 카드가 두 번 보인다. 보유 목록의 출전 중인 카드는 오른쪽 위 작은 칸 번호로만 구분돼 눈에 잘 띄지 않는다.
  - 4:3에서는 아이콘이 크게 늘어나 글자보다 그림이 훨씬 크다(`ratio_4x3_b.png`).
  - 이 화면에 들어올 길이 라운드 시작뿐이고, R1–R7에는 아예 없다(N1).
- 제안: 라운드에서 왔으면 버튼을 '출전 ▶', 로비에서 왔으면 '저장'으로 바꾼다. 제목은 탭에 맞춰 '유닛 5/5', '스킬 3/3'으로. 보유 목록에서 출전 중인 카드는 체크 표시를 크게 하고 흐리게. 로비에 '편성' 입구를 만든다.

### 2.8 전투 HUD (`09_battle_hud.png`)
- 좋음: 네 귀퉁이 배치가 명확하다(왼쪽 위 밀가루, 가운데 위 기지 체력·웨이브, 오른쪽 위 미니맵·일시정지·배속, 아래 이동·견습생·카드·스킬). 터치 칸 사이 8px 간격, 위협 표시 44px 이상 같은 규칙이 `hud_layout.gd`에 정해져 있다. 카드 대기는 아래에서 위로 밝아진다(`0dbb504`).
- 문제:
  - 일시정지·배속 버튼이 작고 배속 버튼이 배경 위에 떠 있어 잘 안 보인다.
  - 카드 비용(밀가루)과 스킬 비용(기력)이 같은 숫자 모양이라 어느 자원을 쓰는지 아이콘으로 구분되지 않는다.
  - 4:3에서는 하늘이 화면의 절반 이상이고 HUD가 작다(`ratio_4x3_b.png`).
- 제안: 비용 숫자 앞에 밀가루/기력 작은 아이콘을 붙인다. 배속 버튼에 판(배경)을 깐다. 4:3에서는 카메라를 아래로 맞추거나 HUD 배율을 한 단계 올린다.

### 2.9 일시정지 (`10_pause.png`)
- 좋음: 화면을 어둡게 하고 가운데 4개 버튼, '계속하기'가 강조색.
- 문제: '다시하기'·'메뉴'가 확인 없이 바로 실행된다(N4). '메뉴'가 로비로 간다는 것이 이름에 없다.
- 제안: '다시하기'·'메뉴'는 '이번 라운드 진행이 사라집니다' 확인창을 거친다. '메뉴' → '본부로'.

### 2.10 결과 (`11_result_win.png`, `12_result_lose.png`)
- 좋음: 별 왕관, 왼쪽 별 조건 / 오른쪽 기록 두 칸, 첫 클리어 보너스와 '강화를 눌러 보세요' 안내, 강화 버튼 '!' 배지, 다음 라운드 강조.
- 문제:
  - 제목 '승리!'가 12px 글꼴을 3배 키운 글자라 뭉개진다(그림 교체 키트 `docs/art/release_slice/result_title_regen/`).
  - 패배 화면에 '왜 졌는지·다음에 무엇을 할지' 안내가 이 라운드에는 없다(패배 힌트가 있는 라운드에만 나온다).
  - 버튼 4개가 같은 크기로 한 줄이라 '다음 라운드' 외에는 위계가 약하다. '메뉴'는 로비로 간다.
  - 상점 입구는 강화 창 안의 '골드 구매'뿐이다(N5).
- 제안: 제목 그림 교체. 패배에는 공통 힌트(강화 추천, 편성 바꾸기)를 늘 한 줄 넣는다. '메뉴' → '본부로'.

| --- | --- | --- |
| 16:9 (640×360) | 640×360 | 기준. 겹침·잘림 없음. |
| 19.5:9 폰 (1560×720) | 780×360 | 좌우로 넓어지고 HUD는 귀퉁이에 붙는다. 로비·상점 가운데 여백이 커지지만 겹침·잘림 없음. 전투 카드와 견습생 사이 간격이 넓어진다. |
| 4:3 태블릿 (960×720) | 960×720 (정수 배율 1) | 가장 약한 경우. 라운드 선택 타일·출전 준비 아이콘이 세로로 크게 늘어나고, 상점·로비·결과는 작은 내용이 넓은 빈 화면 가운데 떠 있다. 전투는 하늘이 절반 이상. |

4:3은 정수 배율이 1로 떨어지는 해상도에서 특히 나빠진다(960÷640=1.5 → 1). 태블릿을 지원한다면 논리 화면 높이에 상한을 두고 타일·아이콘 크기에 상한을 거는 것이 먼저다.

## 4. 공통 원칙 점검

| 항목 | 상태 | 메모 |
| --- | --- | --- |
| 뒤로 가기 위치 | 부분 | 화면은 왼쪽 위 '뒤로', 창(강화·설정)은 아래 '닫기'. 하나로 통일 권장. |
| 안드로이드 뒤로 키 | 좋음 | 모든 화면이 `NOTIFICATION_WM_GO_BACK_REQUEST`를 처리하고, 창이 열려 있으면 창부터 닫는다. 타이틀은 종료 확인. |
| 화면 스택 | 없음 | 이름 지정 이동이라 '온 곳으로 돌아가기'가 안 된다(N2, N3). |
| 지갑 표시 | 부분 | 위치가 화면마다 다르다(타이틀 왼쪽 위, 로비·라운드 선택 오른쪽 위, 상점 가운데). 오른쪽 위 한 자리 + 눌러서 상점 권장. |
| 탭 모양 | 약함 | 출전 준비의 유닛/스킬, 상점의 골드/성장 팩 모두 일반 버튼처럼 보이고 선택 상태가 색뿐이다. |
| 색만으로 전달 | 있음 | 설정의 켜기/끄기, 탭 선택, 강화 '골드 구매' 활성 여부. 체크·테두리·글자 중 하나를 더한다. |
| 위험한 동작 확인 | 없음 | 일시정지의 다시하기·메뉴(N4). 종료만 확인창이 있다. |
| 글자 크기 | 좋음 | 12/24/36px 픽셀 글꼴 정수 배율, 숫자 최소 12px 규칙이 있다(`ui_style.gd`). |
| 터치 칸 | 좋음 | HUD는 8px 간격과 44px 이상 규칙. 로비·상점 위쪽 작은 버튼(뒤로, 골드 상점, 성장 팩)은 높이 약 28px로 작은 편. |
